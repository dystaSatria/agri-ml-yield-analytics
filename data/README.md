# Data Sources

Raw and processed data are not committed to Git because of file size and licensing. Place downloaded files in `data/raw/` and generated outputs in `data/processed/`.

| Dataset | Source | Format | Used for |
|---------|--------|--------|----------|
| Multispectral satellite imagery | Sentinel-2, Copernicus Programme (ESA) | GeoTIFF | NDVI and vegetation indices |
| Daily weather | NASA POWER (https://power.larc.nasa.gov) and local meteorological agency | CSV / API | Rainfall, temperature, humidity features |
| Crop production statistics | Badan Pusat Statistik (BPS), FAOSTAT | CSV / Excel | Yield targets |
| Leaf disease images | PlantVillage (Hughes & Salathé, 2015) and limited field images | JPG / PNG | Disease classification |
| Commodity prices | Government food price portals, market panels | CSV / API | Price forecasting |
| Soil data | National soil maps, laboratory results | Shapefile / CSV | Land condition features |

Each dataset should be recorded in a data catalogue with its origin, licence, coverage period, spatial and temporal resolution, and retrieval date.

`data/sample/` contains a **synthetic** dataset generated by `src/generate_sample_data.py`. It is for testing only and must not be used to report real results.
